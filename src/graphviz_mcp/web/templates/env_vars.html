Environment variables

graphviz-mcp is configured entirely through environment variables with the GVMCP_ prefix, read once at startup. An invalid value stops the server with an error. Unset or empty variables use the default. The values in effect right now are listed on the current environment page.

Using them

With Docker, pass them with -e:

docker run --rm -p 127.0.0.1:8000:8000 \
  -e GVMCP_TIMEOUT_S=60 -e GVMCP_ATTR_POLICY=allowlist \
  graphviz-mcp

Without Docker, export them before starting the server:

GVMCP_PORT=9000 GVMCP_LOG_LEVEL=DEBUG graphviz-mcp

Binding to a non-localhost name requires adding that name to GVMCP_ALLOWED_HOSTS, otherwise requests with that Host header are refused. In the Docker image the server listens on 0.0.0.0 inside the container; publish the port on 127.0.0.1 to keep it local.
