graphviz-mcp itself is released under the MIT License (see `LICENSE`). The Docker image also contains the software listed below, each under its own license. The image keeps the license and copyright files: 
- `/usr/share/doc/graphviz-mcp/` (this file and `LICENSE`; the Web UI also serves them at `/ui/legal/third-party-notices` and `/ui/legal/license`),

## Graphviz

* Graphviz 16.1.0, built from the upstream source release
  (<https://gitlab.com/graphviz/graphviz/-/package_files>, tarball `graphviz-16.1.0.tar.gz`, SHA-256 pinned in the
  `Dockerfile`). Source: <https://gitlab.com/graphviz/graphviz>.
* License: **Eclipse Public License 1.0** (`/opt/graphviz/share/licenses/COPYING`). Some files carry the
  **Common Public License 1.0** (`cpl1.0.txt`, shipped alongside).
* Graphviz is run only as a separate process; graphviz-mcp does not link against it. Graphviz is not modified.

## System libraries in the image (Debian)

Graphviz's rendering plugins and the Python runtime need these shared libraries. They are installed unmodified
from Debian, dynamically linked, and their license texts are in `/usr/share/doc/<package>/copyright`. Several are
LGPL or MPL licensed (weak copyleft for the library itself, not for programs that use it); this is a property of the
container image, not of graphviz-mcp's Python code, whose dependencies are all permissive (see below).

| Library (Debian package) | Used for | License (see the package's copyright file) |
|---|---|---|
| cairo (`libcairo2`) | PNG, PDF, PS, SVG rendering | LGPL-2.1 or MPL-1.1 |
| pango (`libpango-1.0-0`, `libpangocairo-1.0-0`, `libpangoft2-1.0-0`) | text layout | LGPL-2.0+ |
| glib and friends (pulled in by pango) | utilities | LGPL-2.1+ |
| librsvg (`librsvg2-2`) | SVG image input | LGPL-2.1+ |
| gd (`libgd3`) | JPEG, GIF, WebP, GD output | GD license (BSD-like) |
| libwebp (`libwebp7`) | WebP | BSD-3-Clause |
| freetype (`libfreetype6`), fontconfig (`libfontconfig1`, `fontconfig`) | fonts | FreeType License; MIT-style |
| expat (`libexpat1`) | XML parsing | MIT |
| libltdl (`libltdl7`) | plugin loading | LGPL-2.1+ |
| GTS (`libgts-0.7-5t64`) | triangulation for overlap removal (`sfdp`, `prism`, `gvmap`) | LGPL-2.0+ |
| ANN (`libann0`) | nearest neighbours for `mingle` | LGPL-2.1+ |
| zlib (`zlib1g`) | compression | zlib |
| Python 3 (`python3`) | runs the server | PSF-2.0 |
